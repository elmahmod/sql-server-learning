# SQL Server Learning

Welcome to my SQL Server learning repository!

This repository documents my journey in learning **relational databases, database design, and Microsoft SQL Server** through theory, SQL scripts, and practical exercises.

## Learning Topics

- **Database Fundamentals** — Databases, DBMS, RDBMS, keys, and data integrity.
- **Database Design** — Entity-Relationship Diagrams (ERD) and relational schemas.
- **SQL Fundamentals** — Data Definition Language (DDL) and Data Manipulation Language (DML).
- **SQL Queries** — SELECT, filtering, sorting, grouping, and aggregate functions.
- **Relationships & Joins** — Working with related tables.
- **Database Constraints** — Primary keys, foreign keys, and other constraints.
- **Normalization** — Organizing data and reducing redundancy.
- **Practical Projects** — Applying database concepts through hands-on exercises.

## Tools & Technologies

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL
- ERDPlus / draw\.io

The purpose of this repository is to organize my learning progress, practice database concepts, and build a reference for future projects.
